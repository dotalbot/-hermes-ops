# JellySSH mobile UX review

Read-only project review. Code review does not replace visual/device acceptance.

Check terminal readability, keyboard and focus transitions, connection/reconnect state, destructive-action confirmation, accessibility semantics, text scaling, small-screen layout, platform conventions, and failure recovery. Require screenshots or device evidence for user-visible changes and identify the exact build/commit shown.

Return evidence, severity-ordered findings, missing visual/device evidence, and `PASS` or `BLOCK`.
